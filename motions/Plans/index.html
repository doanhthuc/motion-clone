002 Design Principles

# Principle Rationale
01 Manual GPU Control User decides when to unload Ollama. No auto-orchestration.
02 Isolation ComfyUI in own venv. No system Python pollution.
03 Reproducibility All config in scripts. Can rebuild from scratch.
04 Safety First Verify each phase before proceeding.
05 Simplicity Bias No over-engineering. Web UI as primary interface.

003 Critical Rules

▲ Rule 01 · Ollama Unload (Manual)

BẮT BUỘC trước mỗi workflow:

1. Check VRAM với vram-check.sh
2. Nếu < 28GB free → ollama-free.sh
3. Verify lại VRAM
4. Mới start ComfyUI
▲ Rule 02 · PyTorch Compute Capability

Sau mỗi lần install/update PyTorch hoặc custom nodes:

torch.cuda.get_device_capability(0) == (12, 0)

Nếu không phải (12, 0) → PyTorch sai version, ComfyUI sẽ crash.

▲ Rule 03 · Audio Passthrough

Output video PHẢI có audio từ source:

  • Test workflows (5s): ComfyUI native (VHS nodes)
  • Production workflows (30s): FFmpeg post-merge via audio-merge.sh

source ~/.bashrc

Philosophy

Scripts là tool support, không phải auto-orchestration. User vẫn kiểm soát quyết định.

Audio Merge Script Spec

audio-merge.sh <source_video> <silent_video> <output_video>

# Behavior:
# 1. Extract audio from source
# 2. If no audio → copy silent as output, log warning
# 3. Merge audio + silent video
# 4. Handle duration mismatch (-shortest)
# 5. Preserve audio quality (-c:a aac -b:a 192k)

007 Audio Handling

Wan 2.2 Animate chỉ sinh video frames, không xử lý audio. Cần pipeline audio passthrough riêng.

3 Approaches

ApproachMethodProsCons
01 · ComfyUI NativeVHS_LoadVideo có audio outputSingle workflowCần verify với 30s
02 · FFmpeg Postaudio-merge.sh sau khi genReliable, full controlCần 2 steps
03 · HybridComfyUI silent + auto mergeBest UXCần watcher script

Edge Cases

CaseHandling
Source no audioSkip merge, output silent
Audio > Video durationTruncate với -shortest flag
Audio < Video durationUse -shortest flag
Multi-channel (5.1)Preserve as-is hoặc downmix stereo
HEVC/AV1 codecFFmpeg handles all codecs
FPS mismatch sau RIFEAudio không bị stretch (RIFE chỉ đổi FPS)
